# Experimental method and reproduction boundaries

## Populations and provenance
The primary design crosses six authored configurations with 16 injected defects, ten legitimate changes and three ambiguities each. Its 918 baseline routes share a generator. Four separately implemented emitter/adaptation paths contribute five defects, three legitimate cases and two ambiguities each; their 53 baseline routes are not four field sites. The 96 compositions are reused regression inputs, not a holdout.

The Pandoc pipeline uses five complete, byte-verified, MIT-licensed public Markdown files from the same Polyglot repository used by the fourth adaptation. It executes five metadata reads and 53 HTML compilations for 11 releases. An authored template/header integration emits metadata; the contract uses separately retained source-index facts rather than candidate HTML. Input separation is not independent oracle ownership. Native Jekyll/Polyglot, Astro, Hugo and Next.js builds, Liquid execution and complete upstream-site body-link coverage remain absent. Compiler warnings are retained.

## Comparators
Authored route/state, reachability, HTML-only, joint-output and strict-policy scopes are not represented as named products. Suppressing identity/channel findings is a sensitivity analysis, not a separately engineered competing system.

The external comparison instead executes pinned Crawl Cove source. Reproducible preparation removes the unavailable XML dependency and sitemap-only code while preserving evaluated page functions. The harness injects local responses and blocks network fetch. Raw findings remain in `external-page-raw.jsonl.gz`. Only severity error rejects a release; warning-only x-default observations are not false positives. Shared stale-target, identity-swap and explicit-policy cohorts are separated. Extra manifest information is not mistaken for better link analysis under identical information.

## Oracle and exactness
The full evaluator is independent of the tracked owner predicate. Record, expanded-field and coalesced-field caches deliberately share that predicate. Safe transactions wrap the field engines. Every path returns identical complete issue tuples on 321 retained snapshots. Expected diagnostics, legitimate cases and ambiguities have distinct checks. Literal parser and schema regressions execute archived LocaleMesh code as negative controls. The current 75 offline unit methods include additional stateful histories, finite deletion lattices, ownership, rollback, footprint expansion, affected-owner equivalence and live-pool checks. The retained summary's 73 executed methods and coverage figures describe an earlier run, not the current suite's coverage.

The retained optional Chromium experiment uses actual inert DOMParser and separate selectors. Its 30 tree-boundary inputs produce 25 matching selected observations and five diagnosed differences; 18 have literal expected native canonicals. All 53 retained Pandoc outputs and 11 compiled release decisions agree in that native run. The current offline tree-projection record reports 26/30 matching boundary cases: nested_raw_title now matches, and noscript remains diagnostic. It reanalyzes only the 30 retained boundary cases, not the 53 compiled-output checks or 11 native-gate checks, and records no new browser execution. Requests and input-script sentinels belong to the retained native run. Shared URI normalization and authored selectors limit independence. This is not an external human policy oracle or a browser-wide conformance suite.

## Timing design
Record scale: 3 sizes × 4 changes × 12 repetitions = 144. Controlled record fan-out: 12 points × 12 = 144. Expanded field: 3 sizes × 6 changes × 12 = 216. Coalesced comparison: another 3 sizes × 6 changes × 12 = 216, evaluating full, expanded and coalesced cores plus both validated APIs in each row. There is untimed forward/reverse warm-up. Directions alternate; core order rotates and the new paired API order alternates. The same complete issue set is exported and checked. The coalesced comparison also checks identical invalidated-owner counts and expanded logical edge counts.

Snapshot differencing is measured separately. Combined costs are computed per row before medians. Ratio-of-medians and paired-ratio summaries are named separately. Inclusive quartiles, ranges and twelve within-process samples are reported, not population confidence intervals. No latency from one historical run is paired with a new run's denominator. All six changes, including adverse alias and broad-update cases, remain in the table.

## Memory and resource accounting
Separate tracemalloc measurements include owned input facts, indexes and cached findings for each cache. They are not whole-process RSS or earlier index-only figures. Initialization under tracing is not substituted for ordinary latency. Process high-water RSS is recorded separately. The fresh runner records CPU affinity/quota, memory limit, disk and environment, sets a fixed hash seed and one numeric-library thread, and executes measurements sequentially.

## Reproduction
`run_full.sh` invokes 43 stages through `run_all.py`, without cached-stage reuse. Only an all-zero completed execution is a verified full run. Tests and experiments precede four analyses, citation/result audits, compilation and PDF preflight. Reanalysis of delivered data is distinct from executing the measurements. The compilation stage calls `python ../paper/build.py` with the runner's Python interpreter. The builder checks its temporary TeX log for undefined references and horizontal overflow before retaining only the anonymous `paper/main.pdf`.

The final preflight inspects that anonymous PDF: references must begin on page nine, total length must be at most twelve, unresolved-reference markers must be absent, and author text/metadata must remain anonymous. It does not require `main.log` or an identified-author copy, and does not claim to verify unavailable TeX diagnostics or visual layout. For a read-only check of the supplied PDF, `python scripts/pdf_preflight.py --output /path/to/private/pdf-preflight.json` writes the report outside retained results. Rendered-page inspection is separate. `analyze.py`, `analyze_revision.py`, `analyze_coalesced.py` and `analyze_sliced.py` regenerate quantitative tables and plots from raw results.
