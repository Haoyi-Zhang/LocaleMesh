Source review completed 7 October 2026. This is a source-review ledger, not an assertion that every publisher supplied a full PDF. Bibliographic metadata and the specific cited scope were checked using primary publishers, author records, official standards, or project documentation. Access limitations are retained below. The executable audit separately checks citation and metadata consistency.
